## 좌표
- 경로선·길목 좌표는 지도 서비스 없이 수기로 넣은 **대략적인 값**(소수점 3~4자리). 시뮬레이션·방향 계산 데모용이며 실제 서비스에서는 NaviHelper 경로와 TourAPI 좌표로 대체.

## 이미지
- 모든 길목 그림은 Jetpack Compose `Canvas` 로 직접 그린 플레이스홀더 일러스트 (`ui/components/Art.kt`). 외부 사진·아이콘 파일을 쓰지 않았다.
- 실제 서비스에서는 한국관광공사 TourAPI 가 제공하는 관광지 사진(이용 조건 확인 후)으로 교체할 자리.

## 플랫폼 문서
- Pleos Playground 개발자 문서: https://document.pleos.ai/en/api-reference/connect-sdk-pleos/ (NaviHelper SDK v3.0.5 소개 페이지 확인. 호출 순서 initialize → addListener → 요청 → 콜백 → removeListener → release)
- FusedLocation SDK 문서 예시 의존성: `ai.pleos.playground:FusedLocation:1.0.4` (문서에 "준비 중" 표기 있음)
